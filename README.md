## Tech Stack (all free)

| Layer      | Tool                         | Cost  |
|------------|------------------------------|-------|
| Framework  | Next.js 14 (App Router)      | Free  |
| Auth + DB  | Supabase                     | Free  |
| AI Model   | Groq API · Llama 3.3 70B     | Free  |
| Deployment | Vercel                       | Free  |

## Features

- 🤖 AI answers any DSA question (Llama 3.3 70B via Groq)
- 📚 12+ topics · 60+ subtopics
- 🎯 Beginner / Intermediate / Advanced adaptive responses
- 📝 Chat history saved + searchable
- 👤 User accounts (email · Google · GitHub)
- 💸 Zero cost to you

## Quick Start

```bash
git clone https://github.com/palakchandak8/dsa-mentor.git
cd dsa-mentor
npm install
cp .env.example .env.local   # fill in your 3 keys
npm run dev                  # http://localhost:3000
```

## Environment Variables

```
NEXT_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
```
